# Recall Studio user stories

This backlog reflects the workflows currently represented in Recall Studio.

## Getting started and Ableton connection

1. As a producer, I want to set my name or alias so Recall feels personal on my computer.
2. As a producer, I want to see whether Ableton is connected so I know whether Recall can capture my work.
3. As a producer, I want Recall to detect likely Ableton User Library locations so setup is less error-prone.
4. As a producer, I want to choose my actual User Library path so I can install the bridge even if my setup is non-standard.
5. As a producer, I want to install the Recall control surface into Ableton so my work can be captured automatically.
6. As a producer, I want clear post-install steps so I know how to activate Recall inside Ableton.
7. As a producer, I want to see the shipped and running bridge versions so I can diagnose an out-of-date setup.

## Project desk

8. As a producer, I want to create a project for a song so my captures stay organized.
9. As a producer, I want to start a quick take so I can begin recording work without much setup.
10. As a producer, I want to start another take for an existing project so new work is connected to its history.
11. As a producer, I want to connect an Ableton folder to a project so Recall can find saved `.als` versions.
12. As a producer, I want to rescan a connected folder so newly saved versions appear in Recall.
13. As a producer, I want to search my projects so I can find a song quickly.
14. As a producer, I want to sort projects by name, take count, or recency so I can browse in the way that fits my task.
15. As a producer, I want to see project, take, moment, and recording totals so I understand the state of my studio at a glance.
16. As a producer, I want to expand a project's takes so I can see its individual captured sessions.
17. As a producer, I want to rename a project so the library reflects how I refer to the song.
18. As a producer, I want to archive a finished or inactive project so my active desk stays focused.
19. As a producer, I want to open a project's report, briefing, versions, or timeline so I can move directly to the view I need.

## Project briefing and versions

20. As a producer, I want to resume the latest take so I can pick up work quickly.
21. As a producer, I want to see when a project was last worked on so I can prioritize stale ideas.
22. As a producer, I want to see the project's current tracks and device chains so I can reorient myself before editing.
23. As a producer, I want to identify tracks that are active, untouched, or empty so I can spot gaps in the arrangement.
24. As a producer, I want to view every saved version of a project so I can understand its lineage.
25. As a producer, I want to see the sittings attached to each version so I can distinguish saved files from separate work sessions.
26. As a producer, I want to compare a version with the preceding one so I can see added or removed tracks and devices.
27. As a producer, I want to see activity counts for a version so I know how much creative, mix, and sound-design work happened.
28. As a producer, I want to compare mix activity with the previous version so I can judge whether a pass was exploratory or focused.
29. As a producer, I want to relink a captured take to its Ableton file so a moved file does not break its history.
30. As a producer, I want to remove an incorrect take so my project record remains trustworthy.

## Session reports and project history

31. As a producer, I want a plain-language session report so I can understand what happened without reading raw events.
32. As a producer, I want to read a report for one sitting, a full version, or an entire project so I can choose the right level of context.
33. As a producer, I want to switch among captured versions from the report so I can review different stages of a song.
34. As a producer, I want Recall to show how current the report is so I do not mistake stale analysis for live data.
35. As a producer, I want to see the tracks I touched and where most work landed so I can understand the session's focus.
36. As a producer, I want to see when work happened across a session so I can recognize bursts of experimentation or long pauses.
37. As a producer, I want to filter decisions by kind of work so I can focus on arrangement, sound, mixing, or notes.
38. As a producer, I want to inspect the evidence behind a report insight so I can trust and retrace the conclusion.
39. As a producer, I want to compare one captured session against another baseline so I can understand how the project changed.
40. As a producer, I want to set a goal and listening focus for my next pass so the next session starts with intention.
41. As a producer, I want to see every work session on a navigable project map so I can understand the full evolution of a song.
42. As a producer, I want to zoom, pan, and use the keyboard on the project map so I can navigate a long project history efficiently.
43. As a producer, I want to select a work stretch and open its report or workspace so I can move from overview to evidence.
44. As a producer, I want to see which files Recall found on disk so I can understand what artifacts belong to the project.

## Timeline workspace

45. As a producer, I want a visual memory of the Ableton set so I can recognize its structure at a glance.
46. As a producer, I want to see the sequence of work sessions and the gaps between them so I can understand the project's pace.
47. As a producer, I want to open a track's memory so I can see what I did to that track.
48. As a producer, I want to inspect a device chain on a track so I can reconstruct its signal path.
49. As a producer, I want to see a control's first-seen and final values so I can remember where I left a sound.
50. As a producer, I want to see whether controls changed, stayed the same, or have automation active so I can work confidently from the captured state.
51. As a producer, I want to see MIDI edits, clip additions, recordings, and parameter changes in chronological order so I can retrace creative decisions.
52. As a producer, I want repeated adjustments grouped together, with the option to expand them, so dense sessions remain readable.
53. As a producer, I want to flag a track note as a keeper so important ideas stand out later.
54. As a producer, I want to add notes directly to a track's timeline so context stays attached to the work.
55. As a producer, I want to inspect raw capture detail when necessary so I can move beyond the summarized story.
56. As a producer, I want to rebuild a timeline from the saved record so I can validate or refresh Recall's interpretation.
57. As a producer, I want to export a project record as Markdown, text, JSON, or PDF so I can keep a portable copy.

## Release organizer

58. As a producer, I want to create a release project so I can organize an album, EP, or single separately from session history.
59. As a producer, I want to add cover art, artist details, a release date, and release notes so the release has useful context.
60. As a producer, I want to build and reorder a tracklist so the release reflects its intended sequence.
61. As a producer, I want to link an Ableton set to each release track so source work and release planning stay connected.
62. As a producer, I want to reveal a linked Ableton set in its folder so I can open or manage the exact source file from Explorer.
63. As a producer, I want to add mix exports to a track so I can keep versions together.
64. As a producer, I want Recall to measure loudness, peak, duration, and format information so I can assess a mix objectively.
65. As a producer, I want to select a final export so the chosen mix is unambiguous.
66. As a producer, I want to replace or remove an export so the release record stays current.
67. As a producer, I want to play, seek, and adjust the volume of a mix version so I can review it in context.
68. As a producer, I want to add timestamped comments while listening so revision feedback is precise.
69. As a producer, I want to compare mix-version profiles so I can spot differences in loudness, dynamics, and peaks.
70. As a producer, I want a release consistency overview so I can identify mismatched delivery formats, clipping, or loudness issues.
71. As a producer, I want to preview the release as a listener so I can check sequencing and presentation before delivery.

## Planning, notes, and reference

72. As a producer, I want to create tasks with a title, work type, date, and notes so I can plan my studio work.
73. As a producer, I want to view tasks, release dates, and captured sessions in one calendar so my commitments share the same context.
74. As a producer, I want to navigate months and select a week so I can plan both near-term work and deadlines.
75. As a producer, I want to add mix or mastering tasks directly from a release so release work becomes actionable without being assumed.
76. As a producer, I want to open a timeline from a planned item connected to a capture so I can review the relevant work before starting.
77. As a producer, I want to create free-form notes for lyrics, mix checklists, and ideas so they exist outside any one take.
78. As a producer, I want notes to save as I type so I do not lose an idea.
79. As a producer, I want to search my notebook so I can retrieve an old idea or reminder.
80. As a producer, I want to search production terms and filter by category so I can learn while working.
81. As a producer, I want a random production term and practical tip so I can discover something new without knowing what to search for.

## Preferences and support

82. As a producer, I want to choose a full-color or monochrome theme so the interface suits my working environment.
83. As a producer, I want a daily reminder of unfinished tasks and release dates so planning does not disappear between sessions.
84. As a producer, I want to set a reminder time and send a test notification so I can confirm it works.
85. As a producer, I want to see keyboard shortcuts so I can move between studio views quickly.
86. As a producer, I want to report a problem with an optional description and diagnostic record so I can get useful support without manually gathering technical details.
87. As a producer, I want to copy or save the problem report myself so nothing is sent automatically.
